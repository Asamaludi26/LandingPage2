# Nusa Atelier — Digital Flagship & Consultation Platform

> Platform **static SPA** — lead diarahkan ke **WhatsApp Concierge** (tanpa backend/database).

Seluruh dokumentasi proyek dipusatkan di folder **[`docs/`](./docs/README.md)**:

- **[docs/README.md](./docs/README.md)** — Indeks dokumentasi, arsitektur konten, quick start.
- **[docs/PRD.md](./docs/PRD.md)** — Product Requirements Document.
- **[docs/TECH_STACK.md](./docs/TECH_STACK.md)** — Spesifikasi stack & sistem desain.
- **[docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md)** — Arsitektur file & alur sistem.
- **[docs/FAKTA-PELANGGAN.md](./docs/FAKTA-PELANGGAN.md)** — Fakta lengkap untuk komunikasi ke pelanggan (PM).
- **[docs/PANDUAN-KONTEN.md](./docs/PANDUAN-KONTEN.md)** — Panduan edit konten (`src/content/`).
- **[docs/PANDUAN-DEVELOPMENT.md](./docs/PANDUAN-DEVELOPMENT.md)** — Panduan development: alur kerja, deploy, troubleshooting.

## Quick Start

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint     # tsc --noEmit — wajib zero error
npm run build    # build produksi ke /dist
```
